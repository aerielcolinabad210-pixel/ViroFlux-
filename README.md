
VIROFLUX: FORECASTING CONTINUOUS SPIKE MUTATIONAL TRAJECTORIES OF SARS-CoV-2 USING NEURAL ORDINARY DIFFERENTIAL EQUATION AND LATENT-SPACE MODELLING MACHINE LEARNING FRAMEWORK

ViroFlux is a machine learning framework that models and forecasts the continuous mutational dynamics of the SARS-CoV-2 spike protein using latent-space representation learning and Neural Ordinary Differential Equations (NODEs).

Project: ViroFlux
Purpose: Academic research and scientific investigation
Source Code: Complete implementation of the proposed framework.
